《辐射：避难所》2.7.0 Steam 简体中文汉化补丁
================================================

适用版本
--------
Fallout Shelter 2.7.0（Steam，Unity 6 版本）
游戏目录：D:\Program Files (x86)\Steam\steamapps\common\Fallout Shelter

修改内容
--------
1. 游戏内 14,073 条本地化文本（界面、任务、对话、物品、教程、提示等）
   中的英文文本已替换为简体中文。
2. 保持原语言列表名称不变（English），但该语言槽内的文本已全部替换为中文，
   因此中文/英文 Steam 客户端都会直接显示中文。
3. 游戏内嵌的 7 个字体已替换为支持简体中文的 SimHei 子集
   （含 GB2312 常用字、拉丁字母、数字、标点与基础西里尔字母），
   并禁用了 FontManager 中仅含 ASCII 的位图字体，避免中文显示为空。
   已验证游戏内标题“欢迎来到”正常渲染。
4. 仅修改一个文件：FalloutShelter_Data\data.unity3d。
   其余语言（西班牙语、法语、意大利语、德语、俄语）保留原样。

安装方法
--------
把整个“汉化补丁”文件夹放到 FalloutShelter.exe 所在目录（游戏根目录），
然后双击运行“安装汉化.bat”。
安装脚本会先把原版 data.unity3d 备份为 data.unity3d.en.bak，再覆盖。
如果提示权限不足，请右键“以管理员身份运行”。

还原英文
--------
双击“还原英文.bat”，会从 data.unity3d.en.bak 恢复原版。

完整原始备份
------------
D:\FS_localization_work\GameBackup_2.7.0_original
（修改前的整个游戏目录，738 MB）

已知限制
--------
1. 图片/贴图中的英文（例如标题 LOGO、“WELCOME TO”等）无法通过文本替换汉化。
2. 机翻文本经过术语表与常用 UI 人工校正，但少量剧情对话仍可能有生硬之处。
3. 玩家自定义的避难所名、居民名若包含生僻字，可能显示为方框；
   字体已包含 GB2312 常用字，覆盖绝大多数日常用字。

注意：在 Steam 中执行“验证游戏文件完整性”会用原版覆盖 data.unity3d，需要重新运行安装脚本。
