## Fallout Shelter 2.7.0 简体中文汉化 v1.0.0

首个公开版本。

### 内容
- 14,073 条 I2 Localization 文本，14,038 条已替换
- 界面、任务、对话、物品、教程、提示
- 7 个内嵌字体替换为 Unity 兼容的 SimHei 精简子集
- 禁用 FontManager 中仅含 ASCII 的位图字体，修复中文空白

### 安装
1. 解压 `FalloutShelter_2.7.0_zh-CN_v1.0.0.zip`
2. 把整个文件夹放到 `FalloutShelter.exe` 同级目录
3. 运行 `安装汉化.bat`
4. 通过 Steam 启动游戏

或手动把 `data.unity3d` 覆盖到 `FalloutShelter_Data\data.unity3d`。
安装脚本会先备份原版为 `data.unity3d.en.bak`。

### 文件校验
- `data.unity3d` MD5：`aeb2e63b1d905451f501b5814eb94c09`
- 发布包 MD5：`0b9bad7fdc7bd0ef288684a5514527de`

### 还原
运行 `还原英文.bat`，或恢复 `data.unity3d.en.bak`。

### 说明
- 图片/贴图中的英文无法通过文本替换汉化。
- 机翻文本经过术语表和常用 UI 人工校正，少量剧情仍可能生硬。
- 仅用于合法拥有的游戏副本。
