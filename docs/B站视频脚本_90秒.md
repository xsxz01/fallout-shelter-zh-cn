### 3.2 每个源文件怎么录

先准备：

- OBS 输出 1920×1080、60fps、CQP 18，录制格式 MKV
- 不录麦克风，旁白后期加
- 关闭 Steam 通知、好友弹窗、录屏软件水印
- 鼠标开启指针高亮，操作放慢 20%
- 每个镜头前后多录 3–5 秒，方便剪辑

#### A1 Steam 库存

1. 打开 Steam → 库，搜索 `Fallout Shelter`。
2. 让游戏页停在画面中央，缓慢滚动。
3. 录 15–20 秒；不要点启动。
4. 后期会模糊账号和动态区域。

#### A2 英文版没有中文

1. 先运行安装器，点“还原英文”。
2. 启动游戏，录标题画面。
3. 进入 Settings，展示语言选项，确认没有中文。
4. 录 15–40 秒；不要切换语言。
5. 录完先不要安装汉化。

#### A3 旧汉化包页面

1. 浏览器搜索“辐射避难所 汉化 3DM”。
2. 打开一个旧版本/2024 年页面。
3. 缓慢滚动到发布日期、版本号。
4. 录 20–40 秒；打码广告/账号/下载按钮；不要运行 exe。

#### A4 Steam 更新记录

1. Steam → 库 → Fallout Shelter → 更新/新闻。
2. 展示 2.7.0 版本、9 月 3 日赛季更新。
3. 鼠标停在日期或版本号上 3 秒。
4. 录 15–25 秒；避免露出账号信息。

#### A7 中文标题 + UI + 教程（一条长录）

这是最重要的源文件，录 2–3 分钟，后面会拆成 A6/A7/A11。

1. 安装汉化，启动游戏。
2. 中文标题“欢迎来到”停 5 秒。
3. 依次打开：哔哔小子 → 任务 → 对话 → 教程界面，每个停 2–3 秒。
4. 进入新手教程，依次展示：
   - `{建造区域}`
   - `{居民的特殊属性}`
   - `{训练}` / `{提高}`
   - 建造菜单 / 加速界面
5. 教程文字停留 3–4 秒，不要快速跳过。
6. 录 2–3 分钟，中间不要露账号/Bandicam。

#### A8 安装器识别

1. 关闭游戏，打开 `fs_installer.exe`。
2. 展示自动识别的路径、版本、data 大小、备份状态。
3. 鼠标缓慢移动，不要点击。
4. 录 8–10 秒，路径清晰。

#### A10 游戏内 UI（一条长录）

1. 启动游戏，进入干净存档。
2. 依次录制：
   - 建造菜单
   - 房间/避难所全景
   - 哔哔小子 SPECIAL
   - 任务/物品栏
3. 每个界面 3–4 秒，共 30–40 秒。
4. 不要打开账号/个人资料页面。

#### A12 安装完成 + 还原英文（一条长录）

1. 关闭游戏，打开安装器。
2. 录下安装完成状态、进度条、日志。
3. 点击“还原英文”，录下确认弹窗和进度。
4. 共 10–15 秒。
5. 录完后重新安装汉化，恢复游戏状态。
